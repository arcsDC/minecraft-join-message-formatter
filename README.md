# minecraft-join-message-formatter

A Spigot plugin that formats player join and quit messages with configurable templates and color codes.

## Stack

Primary language: **Java**

## Project structure

- `src/main/java/com/example/joinformatter/JoinFormatterPlugin.java` — Customizes player join and quit messages using a simple template system.
- `pom.xml` — Maven build configuration

## Usage

Review the source files and install any dependencies referenced by the project before running it.
